# MCP Enterprise Server

Production-grade Model Context Protocol (MCP) server built in Python.

## Goals
- Demonstrate real-world MCP patterns
- Clean separation between MCP layer and domain logic
- Secure, observable, and deployable architecture

## Non-Goals
- Toy demos
- Hardcoded prompts or tools
- Model-specific hacks

## Architecture (High Level)
- MCP Server: protocol, schemas, transport
- Tools: side-effectful actions
- Resources: read-only context
- Domain: business logic
- Adapters: external systems
